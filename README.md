# 局域网信息传输系统 (LMTS)

LMTS 是一个轻量级的局域网通知工具，可以在教室、实验室等局域网环境下，向指定电脑发送弹窗消息。  
尤其适合电教委员、老师向全班同学发布通知或提醒。

## ✨ 功能特点

- **简单可靠** – 基于 UDP 协议，接收端固定监听端口，无需额外服务器。
- **醒目的弹窗** – 消息以大字体、置顶窗口显示，并标明发送者 IP。
- **加急模式** – 勾选“加急”后，接收端会连续响铃三声，并自动将系统音量调至 100%（Windows）。
- **频率限制** – 同一个 IP 地址 5 秒内只能发送一次消息，防止刷屏。
- **自动解决端口冲突** – 如果接收端端口 12345 被占用，会自动询问并终止冲突进程（Windows）。
- **一键复制** – 接收者点击“复制”按钮即可将消息内容复制到剪贴板。

## 🖥️ 运行环境与依赖

- **操作系统**：Windows 7/10/11，或 Linux（Ubuntu 20.04 以上）
- **Python 版本**：3.5 或更高
- **必需库**：`pyperclip`

安装命令：
```bash
pip install pyperclip
```

> 注：蜂鸣提示和音量控制功能仅限 Windows。Linux 下接收端仍可正常显示消息，但不会有声音。

## 📥 安装方法

1. 下载两个脚本文件：
   - `display.pyw` – **接收端**（需要显示消息的电脑运行此文件）
   - `send.pyw` – **发送端**（发消息的电脑运行此文件）

2. 直接双击运行即可（`.pyw` 后缀不会显示控制台窗口）。

## 🚀 使用方法

### 1. 启动接收端

双击 `display.pyw`。会短暂弹出一个黑色控制台窗口（很快消失），之后接收端就在后台运行了。  
它会一直监听 **UDP 12345 端口**，收到消息后立即弹出窗口。

### 2. 发送消息

双击 `send.pyw`，打开发送端界面：

- **接收端 IP 地址** – 填写目标电脑的 IP（例如 `192.168.1.10`）
- **消息内容** – 在大的文本框中输入要发送的消息
- **加急** – 如果需要对方响铃并自动最大音量，请勾选此项
- 点击 **发送** 按钮

如果接收端成功收到并确认，你会看到“接收端收到了您的信息”的提示。  
如果同一接收端在 5 秒内再次发送，会提示“发送过于频繁”。

## ⚙️ 高级配置（修改代码）

所有参数都定义在脚本开头的类属性中，你可以根据需要修改：

| 参数名 | 位置 | 默认值 | 说明 |
|--------|------|--------|------|
| `PORT` | `display.pyw` 和 `send.pyw` | `12345` | UDP 通信端口（两端必须一致） |
| `RATE_LIMIT_SECONDS` | `display.pyw` | `5` | 同一 IP 最短发送间隔（秒） |
| `MESSAGE_WIDTH` | `display.pyw` | `30` | 消息自动换行的字符宽度 |
