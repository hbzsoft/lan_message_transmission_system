# 局域网信息传输系统 (LAN Message Transmission System, LMTS)

一个轻量级的 **Windows 局域网弹窗消息工具**：在校园、实验室等局域网环境下，无需服务器即可向指定电脑发送纯文本消息并以醒目的置顶弹窗显示，适合电教委员 / 老师向全班电脑发布通知，或班级内部电脑间快速通信。

- 官方正式版本：**v1.6**
- 官方网站：[https://hanbangze.tech/](https://hanbangze.tech/)
- 许可证：[GNU GPL v3](https://www.gnu.org/licenses/gpl-3.0.html)

## 目录结构

本仓库按版本归档，各版本相互独立：

```
lan_message_transmission_system/
├─ v1.3/                          # 经典初版（完整原创，含用户手册）
│  ├─ send.pyw                    #   发送端
│  ├─ display.pyw                 #   接收端
│  └─ 局域网信息传输系统用户手册.pdf
├─ v1.4/                          # 下游改编版（基于 v1.3 改编）
│  ├─ send.pyw
│  ├─ receive.pyw
│  └─ COPYING                     #   GPL v3 许可证文本
└─ v1.6/                          # ★ 正式版本（推荐使用）
   ├─ send.exe                    #   发送端（已编译，免安装）
   ├─ display.exe                 #   接收端（已编译，免安装）
   ├─ lmts_school.json            #   学校 / 届数 / 班级 配置
   └─ 内置文件(勿删！)/            #   源码与构建工具（勿删，供构建使用）
      ├─ send.pyw                 #     发送端源码
      ├─ display.pyw              #     接收端源码
      ├─ build_exe.bat            #     一键打包脚本
      ├─ allow_firewall.bat       #     一键放行防火墙脚本
      ├─ README_CN.txt            #     编译说明（随包分发）
      ├─ lmts_school.json / lmts_settings.json
      └─ dist/                    #     打包输出目录
```

> v1.6 为**正式版**：目录内直接提供编译好的 `send.exe` 与 `display.exe`，普通用户无需安装 Python 即可使用。

## v1.6 新功能一览

v1.6（含其前身 v1.5 系列开发成果）在 v1.4 基础上引入了面向真实校园使用场景的完整升级：

1. **自动发现接收端**：发送端无需手动填写 IP。程序通过 UDP 广播（255.255.255.255:54321）与组播（239.255.61.61:54321）双重通道每 3 秒广播自身信息，同班级的接收端被发现后自动回传，发送端随即自动填入 IP，接收端主界面同步显示「在线发送端」数量。
2. **班级匹配隔离**：首次运行会弹出「初始配置」窗口，要求填写学校、届数、班级（例如 `nfls / 2025 / 08`），保存于 `lmts_school.json`。只有三者完全一致的电脑才能互相发现与发送，天然实现"本班电脑互通、跨班隔离"，避免打扰其他班级。
3. **接收端可回复消息**：消息弹窗内自带回复输入框，可直接将回复发回发送端；发送端后台常驻监听端口 14514（被占用时自动改用随机端口兜底），回复以置顶弹窗实时弹出。
4. **加急全面增强**：勾选"加急"后，接收端会把系统音量拉满并播放 3 次 2500 Hz 尖锐警报（时长受控，不伤听力），再也不会错过紧急通知。
5. **界面主题与字号自定义**：内置「深蓝 / 暗黑 / 浅色 / 紫夜 / 薄荷」5 套配色，可在窗口内一键切换；消息字号支持 ±实时调节（接收端弹窗随字号等比放大），偏好自动保存于 `lmts_settings.json`。
6. **端口冲突自动修复**：接收端启动时若 12345 端口被占用，自动通过 `netstat` + `tasklist` 定位占用进程，询问用户后一键结束并重新绑定。
7. **更稳定的发送链路**：改用监听 socket 发送消息，确保接收端的回执与回复能正确回到发送端；真实消息到达即记为在线，避免广播被网络设备过滤时误显示为离线。
8. **工程化交付**：提供 `allow_firewall.bat`（一键添加仅限本地子网的 UDP 12345 / 14514 / 54321 入站规则）、`build_exe.bat`（自动建虚拟环境、自清华 / 阿里镜像安装 PyInstaller 并打包出 `dist/` 成品）、以及 `send_error.log` / `display_error.log` 运行时错误日志，便于排查。

## 部署指南（v1.6 正式版）

### 方法一：直接使用编译成品（推荐，无需 Python）

1. 从 `v1.6/` 目录获取发布包：`send.exe`、`display.exe`、`lmts_school.json`、`allow_firewall.bat`。
2. 将 `send.exe` 放到"发送端"电脑，将 `display.exe` 放到"接收端"电脑；**两个 exe 须与其同目录的 `lmts_school.json` 保持一致**（确保两台电脑的学校、届数、班级配置完全相同）。
   - 若需修改班级：直接用记事本编辑 `lmts_school.json`，或删除该文件后重新启动程序即可再次填写。
3. 两台电脑连接**同一局域网**。
4. 在**两台电脑**上各以管理员身份运行一次 `allow_firewall.bat`（仅添加本地子网入站的 UDP 规则，安全可控）。
5. 先启动接收端 `display.exe`，再启动发送端 `send.exe`，等待约 3 秒。
6. 发送端会自动发现同班级的接收端并填入 IP；输入消息后点击"发送"即可。若需提醒对方注意，请勾选"加急"。
7. 接收端以置顶大字弹窗显示消息，可一键复制，也可直接在弹窗中输入内容"发送回复"。

> **提示**：若无法自动发现，请先确认两台电脑的学校/届数/班级配置完全一致，其次检查无线路由器是否开启了 **AP 隔离 / 客户端隔离**（需在路由器设置中关闭）；此时也可在发送端手动输入接收端 IP（程序会自动记住上次使用的 IP）。

### 方法二：从源码运行（开发者）

1. 环境要求：Windows + Python 3（建议 3.8 及以上），并安装 `pyperclip` 依赖（`pip install pyperclip`）。tkinter 为 Python 自带。
2. 进入 `v1.6/内置文件(勿删！)/`，双击运行 `send.pyw`（发送端）与 `display.pyw`（接收端）；或命令行执行 `python send.pyw`、`python display.pyw`。
3. 首次运行会弹出"初始配置"窗口，填写学校 / 届数 / 班级后即可使用，操作同方法一。

### 方法三：自行打包 EXE（开发者）

1. 确保已安装 Python 3 并已加入 PATH。
2. 双击 `v1.6/内置文件(勿删！)/build_exe.bat`。
3. 脚本会自动创建隔离构建环境、从国内镜像安装 PyInstaller，并依次编译 `send.exe` 与 `display.exe`。
4. 编译产物输出到 `内置文件(勿删！)/dist/` 目录（含 `send.exe`、`display.exe`、`lmts_school.json`、`allow_firewall.bat`、`README_CN.txt`）。
5. 两台电脑上各运行一次 `allow_firewall.bat` 后即可按"方法一"使用。

> 若打包时提示 EXE 被占用：请先关闭正在运行的旧版 send/display 程序（脚本只会关闭本项目 `dist` 目录内的同名进程）。

## 故障排查

| 现象 | 处理方法 |
| --- | --- |
| `send.exe` / `display.exe` 启动异常 | 查看 EXE 同目录下的 `send_error.log` / `display_error.log` |
| 无法自动发现对方 | ① 核对两台电脑 `lmts_school.json`（学校/届数/班级）一致；② 检查路由器是否开启 AP 隔离；③ 确认已运行 `allow_firewall.bat` |
| 发送后收不到回执/回复 | 确认接收端 12345 端口未被其他程序占用（v1.6 会提示并自动处理） |
| 打包失败 | 使用源码直接运行方式排查（方法二），或检查网络后重新运行 `build_exe.bat` |
